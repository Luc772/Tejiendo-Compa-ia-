# 🧶 Tejiendo Compañía

> **Propuesta de valor:** Compañía y propósito para la tercera edad a través del tejido, el bienestar y la comunidad.

Proyecto de emprendimiento e innovación social que combate la soledad no deseada en personas mayores mediante una plataforma accesible que une actividades manuales con conexión social y familiar.

## Los cuatro pilares

| Pilar | Qué ofrece |
| :--- | :--- |
| 🧶 **Mi Tejido** | Calculadora de puntos y contador de vueltas sin fricción |
| 👥 **Mi Comunidad** | Encuentros presenciales y muro comunitario |
| 🧠 **Bienestar** | Recordatorios de medicamentos, gimnasia cognitiva, pausas activas |
| 💌 **Círculo Familiar** | Fotos y audios de la familia, respuestas con un toque |
