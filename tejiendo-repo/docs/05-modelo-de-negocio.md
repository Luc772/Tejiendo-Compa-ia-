# 5. Modelo de negocio (Lean Canvas)

| Elemento | Detalle |
| :--- | :--- |
| **Segmento de clientes** | Adultos mayores (65+), familiares/cuidadores y entidades institucionales (municipios, centros de día, cajas de compensación). |
| **Propuesta de valor** | Compañía, rutina y propósito activo mediante tejido guiado y comunidad presencial accesible. |
| **Canales** | Alianzas con clubes comunales, centros de tercera edad y mercerías; campañas digitales hacia familiares. |
| **Fuentes de ingreso** | 1. Suscripción freemium (patrones y contenidos avanzados). 2. Licencias B2B2C para municipios y programas de adulto mayor. 3. Comisiones por venta de insumos con comercios asociados. |
| **Estructura de costos** | Desarrollo de software, infraestructura en la nube, curaduría de contenidos y gestión comunitaria. |
| **Métricas clave** | Usuarios activos semanales (WAU), vueltas/proyectos completados, adherencia a medicación, asistencia a encuentros. |
| **Ventaja competitiva** | Accesibilidad nativa (no adaptada), diseñada para el ritmo y necesidades de la tercera edad. |
